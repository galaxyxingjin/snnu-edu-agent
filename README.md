# 师小助 · 智能助学 Agent

> 面向高校「教学赋能」场景的 AI 智能助教：学科答疑、智能评测、讲义/PPT/图解生成，以及特色的**物理具象化实验室**——让看不见的力学、电学、原子物理变得看得见、算得出。

「师小助」是一个基于大模型（LLM）构建的对话式智能教育助手，围绕陕西师范大学「数字赋能教育」赛事方向，聚焦课堂教学与自主学习场景。

## 🎯 面向谁

| 人群 | 主要诉求 | 师小助提供的价值 |
|------|----------|------------------|
| **学生** | 自学、答疑、备考 | 学科答疑、智能出题与批改、学情诊断、物理具象化实验室 |
| **教师** | 备课、课件、讲义 | 讲义/PPT/图解一键生成、物理实验演示辅助备课、联网查教育资讯 |

一句话：对学生是「随身助教」，对老师是「备课帮手」。「物理具象化实验室」是本项目对**学生物理学习**的差异化亮点，其余能力（出题、讲义、PPT、图解）兼顾师生两端。

| 📚 **学科答疑** | 数学、物理、英语、编程等学科讲解，「思路 → 步骤 → 答案 → 知识点」结构化输出 | 模型原生能力 |

| 🖼️ **知识点图解** | 概念关系图、思维导图、函数图像、实验装置图、原子模型图 | `generate_diagram` 工具 |
| 🔬 **物理具象化实验室** | 力学/电学/原子物理三大场景，支持定量模拟（详见下节） | `physics_simulation` + `generate_diagram` |

## 🔬 物理具象化实验室（特色模块详解）

这是一个**独立板块**：既能在解题遇到物理题时被 Agent 自动引导使用，也能作为独立入口主动体验。

### 1. 力学场景

**器材**：木块、小车、小球、斜面、弹簧、细绳、滑轮、量角器、弹簧测力计
**环境参数**：重力加速度 `g`、环境阻力（动摩擦因数 / 空气阻力系数）

| 实验 | 可调参数 |
|------|----------|
| 斜面运动 | 质量、倾角、动摩擦因数、重力加速度、初速度、斜面长度 |
| 自由落体 | 高度、重力加速度、初速度、质量、空气阻力系数 |
| 弹簧（胡克定律/简谐振动） | 劲度系数、形变量、振子质量 |

### 2. 电学场景

**器材**：干电池、学生电源、交流电源、电阻、滑动变阻器、开关、灯泡、电流表、电压表、多用表、导线、电容、电感

| 实验 | 可调参数 |
|------|----------|
| 串联电路 | 电源电动势、内阻、电阻列表 |
| 并联电路 | 电源电动势、内阻、电阻列表 |

### 3. 原子物理场景

**可参观内容**：原子模型展厅（道尔顿、汤姆孙、卢瑟福核式结构、玻尔、电子云模型），以图解/讲解方式呈现。

### 上手示例

- 「帮我做一个斜面运动实验：质量 2kg、斜面倾角 30°、动摩擦因数 0.1」
- 「模拟自由落体，高度 20m，考虑空气阻力」
- 「做一个串联电路模拟，电动势 6V、内阻 1Ω、电阻 [5, 10]」
- 「我想参观原子物理展厅，介绍原子的核式结构模型」

Agent 会输出带**公式与数值**的定量模拟结果并讲解。

## 🏗️ 技术架构

- **Agent 形态**：**单 Agent（ReAct 循环）+ 5 个工具函数**（非多智能体编排）
- **大模型**：豆包 `doubao-seed-2-0-pro`（多模态）
- **短期记忆**：
  - 滑动窗口：默认保留最近 **40 条消息（约 20 轮）**
  - 持久化：PostgreSQL Checkpointer；**若数据库不可用，自动降级为内存 `MemorySaver`（服务重启后记忆丢失）**
- **后端服务**：FastAPI（HTTP 服务，端口 5000）
- **数据存储**：PostgreSQL（用户表 + 对话记忆）；生成的文件/图片/PPT 由 SDK 上传对象存储
- **工具能力**：联网搜索、文档生成、图片生成、物理模拟计算

## 🚀 快速开始

### 本地运行（Agent 对话）

```bash
bash scripts/local_run.sh -m flow
```

### 启动 HTTP 服务（含前端页面）

```bash
bash scripts/http_run.sh -m http -p 5000
```

启动后访问：

- 介绍页：`http://localhost:5000/`
- 注册 / 登录页：`http://localhost:5000/login`
- 对话页：`http://localhost:5000/chat`（登录后自动跳转）

### 部署后如何访问

在平台点「部署 / 发布」触发部署，成功后平台会生成访问入口 URL，复制并打开：

1. 打开入口即是**介绍页**；
2. 点「登录 / 注册」进入登录页，用游客账号 `youke` / `123456`（灰色提示）或注册新账号；
3. 登录后自动跳转到**对话页**，可点顶部快捷入口（如「🔬 物理具象化实验室」）一键体验。

### 账号说明（重要）

- **游客账号**：`youke` / `123456`
- **注册新账号**：登录页切到「注册」填写用户名密码即可，数据存 PostgreSQL，密码 PBKDF2 加盐哈希存储
- ⚠️ **当前为「演示级」登录**：无 session/token 会话鉴权，登录成功后前端以 URL 查询参数 `?user=用户名` 传递身份（可被手工伪造）。仅用于功能演示与账号数据落地验证，**不适用于真实鉴权场景**。

## 🛠️ 二次开发：如何新增一个工具

1. **新建工具**：在 `src/tools/` 下建 `xxx_tool.py`，用 `@tool` 装饰器定义函数（返回 `str`）：

   ```python
   from langchain.tools import tool

   @tool
   def my_tool(arg: str) -> str:
       """工具能力的一句话说明（Agent 据此判断何时调用）。"""
       return f"result for {arg}"
   ```

2. **注册工具**：在 `src/agents/agent.py` 中 import 并加入 `create_agent(tools=[..., my_tool])`。

3. **声明工具**：在 `config/agent_llm_config.json` 的 `tools` 数组补充一句该工具的描述。

4. **写提示词**：在 `config/agent_llm_config.json` 的 `sp`（System Prompt）中说明该工具的使用时机与参数规范。

> 补充约定：`@tool` 函数内部**不要**调用另一个 `@tool` 函数（装饰后会变成 `StructuredTool` 对象，无法直接调用）；需要复用逻辑时抽成普通函数共用。
