# 师小助 · 智能助学 Agent

> 面向高校「教学赋能」场景的一站式 AI 智能助教 —— 学科答疑、智能评测、讲义生成、知识点图解、虚拟物理实验，让教与学提质增效。

「师小助」是一个基于大模型（LLM）构建的对话式智能教育助手，围绕陕西师范大学「数字赋能教育」赛事方向，聚焦**课堂教学与自主学习**场景，用 AI 为师生提供备课、答疑、评测、实验演示等全链路支撑。

---

## 🎯 项目亮点 / 创新点

1. **🔬 物理具象化实验室（核心差异化）**
   把抽象的力学、电学、原子物理知识，变成「看得见、算得出、可交互」的虚拟实验。内置三大场景、十余种虚拟器材，支持调节重力加速度、环境阻力等参数做**定量模拟**，让看不见的物理规律具象化，是同类助学产品中最具沉浸感的教学功能。

2. **📚 全链路教学闭环**
   不止于答疑 —— 覆盖「出题 → 批改 → 诊断」「讲 → 练 → 讲义导出」「图解 → 实验 → PPT 课件」的完整备课/学习流程，一次对话即可产出可下载的教学成果（Word/PDF/PPTX/图片）。

3. **🧠 多模态 + 长期记忆**
   基于多模态大模型，支持文字/图片/视频输入（拍题识别）；对话记忆持久化，问答跨轮不脱节。

4. **🌐 前端完整闭环**
   自建「介绍页 → 注册/登录页 → 智能对话页」三页网站，账号数据落地数据库，游客可一键体验，上手零门槛。

## 🔬 物理具象化实验室（特色模块详解）

这是一个**独立板块**：既能在解题遇到物理题时被 Agent 自动调用，也能作为独立入口供感兴趣的用户主动体验。

### 1. 力学场景

**可用器材**：木块、小车、小球、斜面、弹簧、细绳、滑轮、量角器、弹簧测力计

**可调环境参数**：重力加速度 `g`、环境阻力（空气阻力系数）

| 实验 | 可调参数 |
|------|----------|
| 斜面运动 | 质量、倾角、动摩擦因数、重力加速度、初速度、斜面长度 |
| 自由落体 | 高度、重力加速度、初速度、质量、空气阻力系数 |
| 弹簧（胡克定律/简谐振动） | 劲度系数、形变量、振子质量 |

### 2. 电学场景

**可用器材**：干电池、学生电源、交流电源、电阻、滑动变阻器、开关、灯泡、电流表、电压表、多用表、导线、电容、电感

| 实验 | 可调参数 |
|------|----------|
| 串联电路 | 电源电动势、内阻、电阻列表 |
| 并联电路 | 电源电动势、内阻、电阻列表 |

### 3. 原子物理场景

**可参观内容**：原子模型展厅（卢瑟福核式结构模型等），以图解/讲解方式呈现。

### 上手示例

在对话页直接输入，例如：

- 「帮我做一个斜面运动实验：物体质量 2kg、斜面倾角 30°、动摩擦因数 0.1」
- 「模拟自由落体，高度 20m，考虑空气阻力」
- 「做一个串联电路模拟，电动势 6V、内阻 1Ω、电阻 [5, 10]」
- 「我想参观原子物理展厅，介绍一下原子的核式结构模型」

Agent 会输出带有**公式与数值**的定量模拟结果，并给出讲解。

## 🏗️ 技术架构

- **Agent 框架**：LangChain / LangGraph（`create_agent` 多智能体编排）
- **大模型**：豆包 Doubao-Seed-2.0-Pro（多模态，支持文本/图片/视频输入）
- **短期记忆**：滑动窗口（默认保留最近 20 轮）+ PostgreSQL 持久化 Checkpointer
- **后端服务**：FastAPI（HTTP 服务，端口 5000）
- **数据存储**：PostgreSQL（用户数据 + 对话记忆）+ 对象存储（生成的文件/图片/PPT）
- **工具能力**：联网搜索、文档生成、图片生成、物理模拟计算

## 🚀 快速开始

### 本地运行（Agent 对话）

```bash
bash scripts/local_run.sh -m flow
```

### 启动 HTTP 服务（含前端页面）

```bash
bash scripts/http_run.sh -m http -p 5000
```

启动后访问：

- 介绍页：`http://localhost:5000/`
- 注册 / 登录页：`http://localhost:5000/login`
- 对话页：`http://localhost:5000/chat`（登录后自动跳转）

### 部署后如何访问

在平台点「部署 / 发布」触发一次部署，成功后平台会生成一个访问入口（URL），复制并打开即可：

1. 打开入口即是**介绍页**，浏览功能亮点；
2. 点击「登录 / 注册」进入登录页，可用游客账号 `youke` / `123456`（灰色提示）或注册新账号；
3. 登录后自动跳转到**对话页**，可点击顶部快捷入口（如「🔬 物理具象化实验室」）一键体验特色功能。

### 前端使用说明

- **游客账号**：用户名 `youke`，密码 `123456`（已在登录框以灰色提示显示）
- **注册新账号**：在登录页切换到「注册」标签，填写用户名与密码即可，账号数据持久化存储到数据库
